## 🏝️ Overview

**Morden Tourist** specializes in luxury island escapes, adventure wildlife safaris, family theme park tours, and cultural getaways across the Abu Dhabi Archipelago, Arabian Gulf, Andaman & Nicobar, Lakshadweep Atolls, and Indian coastal destinations.

This repository contains the complete frontend website, responsive island package slider carousel, dynamic tour booking modal with direct WhatsApp dispatch, and an integrated Admin Portal.

---

## ✨ Key Features

- **Responsive Single-Row Package Carousel**: Interactive slider with drag-to-scroll, touch swipe, floating chevron navigation, and pagination dots.
- **Dynamic Category Filtering**: Seamlessly filter packages by theme (*Luxury & Beach, Adventure & Safari, Theme Parks & Family, Culture & Heritage*) and geography (*Arabian Gulf, Indian Ocean/Tropical*).
- **Direct WhatsApp Booking Engine**: All tour inquiries and contact requests format structured WhatsApp messages dispatched instantly to `+91 98052 60021`.
- **Integrated Admin Portal (`admin.html`)**:
  - Secure credentials login (`admin` / `morden2026`).
  - Add, edit, and delete tour packages with live synchronization via `localStorage`.
  - Lead and inquiry tracking table.
- **Comprehensive Page Architecture**:
  - `index.html` — Homepage with hero exploration widget, island spotlights, and service highlights.
  - `tourist-places.html` — Dedicated single-row interactive package slider catalog.
  - `destinations.html` — In-depth guide to 12 featured islands with travel logistics advice.
  - `services.html` — Complete overview of yacht charters, resort booking, visa permits, and MICE tours.
  - `about.html` — Agency story, mission, and travel director profiles.
  - `contact.html` — Consultation form, office hours, and interactive Google Maps embed.
  - Legal compliance: `privacy-policy.html`, `disclaimer.html`, `terms-and-conditions.html`.
